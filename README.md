# Farm Inventory (v1)
Open `index.html` in any modern browser (phone or desktop). No install, no account, no internet needed.
Data is saved in the browser's localStorage on that device — use **Data → Backup (JSON)** regularly and **Import backup** to move data between devices.
Files: index.html, styles.css, app.js. Test: `tests/e2e.playwright.js` (run from a folder with playwright installed).
